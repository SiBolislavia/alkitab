# Technical Skills & Competencies Required

Untuk mengembangkan dan memelihara proyek ini dengan standar industri, pengembang/AI harus menguasai:
1. **Tauri v2 Architecture:** Pemahaman tentang Rust backend, Tauri commands, plugins, dan konfigurasi bundle/resource.
2. **Next.js App Router & Static Export:** Mampu membangun aplikasi React yang dikompilasi menjadi static HTML/JS (`output: 'export'`) agar kompatibel dengan Tauri webview.
3. **SQLite & SQL Optimization:** Kemampuan menulis query SQL efisien untuk pencarian teks lengkap (*Full-Text Search*) pada database Alkitab lokal.
4. **Tailwind CSS & UI/UX Design:** Desain antarmuka desktop yang bersih, responsif, dan mendukung aksesibilitas (accessibility/a11y).
5. **TypeScript:** Penulisan kode yang aman tipenya (*type-safe*) untuk menghindari *runtime error* pada komunikasi IPC.
